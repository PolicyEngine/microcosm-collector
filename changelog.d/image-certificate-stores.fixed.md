Remove "emSign ECC Root CA - G3" and "AAA Certificate Services", the roots that the compromised eMudhra intermediate CA certificates chain to, from the image's own certificate stores. The image now builds from `ghcr.io/astral-sh/uv:0.13.6-python3.13-trixie-slim`, pinned by digest, whose Debian `ca-certificates` 20250419+deb13u1 drops both roots and whose pip 26.2.2 vendors certifi 2026.10.19, which lacks the first; the previous base, `python3.13-bookworm-slim`, is no longer updated and held both. This also moves the image from Debian 12 to Debian 13, Python 3.13.11 to 3.13.18 and uv 0.9.30 to 0.13.6. The collector's Hugging Face check already verifies against the locked certifi and is unchanged. CI now fails if any certificate file in the built image holds either root, matched by SHA-256 fingerprint.
