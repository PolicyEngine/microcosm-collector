A `releases-record` submission kind moves a country's latest calibration tree when its release repo's `releases.json` changes without a new build, as after `microcosm-publish-release-build --promote`. Its one file is the `releases.json` the change wrote; its provenance names the release repo, the commit that wrote it, and the release and build it made current. Under the manifest lock, the worker reads `releases.json` at the repo's head and points the latest at the tree recorded for the default release's current build there, older or newer, with the tree package's new latest command (`src/calibration-tree-latest.ts`), which writes only the manifest. This applies to every country the collector lists.
