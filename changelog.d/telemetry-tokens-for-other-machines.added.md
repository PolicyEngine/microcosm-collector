Issue telemetry tokens for builds on other machines. The token exchange accepts an optional `lifetime_seconds`, a positive integer, only with scope `telemetry:write` (with `artifacts:submit` it answers 422). It grants the requested lifetime up to 86,400 seconds, a constant in the code rather than a deployment setting, reports the granted lifetime in `expires_in`, and marks the token with the claim `"delegated": true`. Every endpoint that accepts `telemetry:write` accepts such a token. An operator's workstation can then exchange its Hugging Face token at launch for a token that a build without a Hugging Face credential, such as a Microcosm stage on Modal, uses for up to 24 hours. Exchanges without `lifetime_seconds` are unchanged.
