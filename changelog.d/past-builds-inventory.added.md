Add the `past-builds` operator command, which prints an inventory of past Microcosm builds as JSON and stores nothing: one entry for each `staged/<run_id>/` folder in each country's Hugging Face release dataset, read at the commit its `main` points at, and for each run in `telemetry_runs`, joined by run ID. Each entry gives the Microcosm commit from the folder's `staged_manifest.json` (`summary.git_commit`), its class (`after_1151`, `between_1144_and_1151`, `before_1144` or `unknown`, with the reason), worked out with GitHub's compare API without a token, one or two requests for each distinct commit, and with every later commit `unknown` after a rate-limit answer or any other failure; the graph files the folder holds; and what can be rebuilt from Hugging Face (`full` with the schema and execution overlay, `declaration_only` with the schema alone, or `none`). Builds made before microcosm#1144, and builds made before microcosm#1151 with nothing to rebuild from, are listed as skipped, with the reason. `telemetry_collector.past_builds.list_past_builds` returns the same inventory to code. The command needs `DATABASE_URL` and `COLLECTOR_HF_READ_TOKEN`, so it runs as an execution of the worker job with its arguments overridden.
