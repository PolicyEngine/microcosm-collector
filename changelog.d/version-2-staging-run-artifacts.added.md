- The collector reads the result files of a version 2 staging run under `runs/<id>/artifacts/`, where Microcosm's version 2 writer puts them and where US builds will write them (microcosm#1135): a structured run's tree is built with the `build_manifest` and `release_manifest` its run manifest declares, each checked against its declared SHA-256, and copies the `reform_validation` and `parent_build_manifest` it declares; a declared manifest the folder lacks makes the run `unbuildable`, and a run that declares none is read from the folder's top level as before.
