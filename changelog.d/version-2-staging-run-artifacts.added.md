- The collector reads the result files of a version 2 staging run under `runs/<id>/artifacts/`, where Microcosm's version 2 writer puts them and where US builds will write them (microcosm#1135). It copies `artifacts/reform_validation.json` for the dashboard beside the top-level `reform_validation.json` of version 1 runs, named by that path in the index. A structured run's tree is built with the `build_manifest` and `release_manifest` its run manifest declares, each checked against its declared SHA-256, and stores copies of the `reform_validation` and `parent_build_manifest` it declares; a declared manifest the folder lacks makes the run `unbuildable`, and a run that declares none is read from the folder's top level as before. `@policyengine/calibration-tree` 0.1.6 adds `artifacts/reform_validation.json` to `STAGING_RUN_FILE_NAMES` and `stagingReformValidationFileName`, `loadCopiedStagingRun` returns a version 2 run's reform validation, and the Hugging Face staging reader reads the same declared paths. Readers of 0.1.5 read the new index without the new copy.
