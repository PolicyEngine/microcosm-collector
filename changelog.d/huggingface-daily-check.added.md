Check Hugging Face daily from a production Cloud Run job, `python -m telemetry_collector.huggingface_check`, started by Cloud Scheduler. It requests every dataset the collector reads with its read token and fails on any answer but HTTP 200. For datasets switched on, it also checks `releases.json` with the rules in the microcosm-emitter-interface package: one record and no `latest*.json` files, the record's rules, and every published file against its build manifest's SHA-256. That part is off for every dataset until the package is published and the datasets have moved to the new layout. Each problem is a structured error log entry, and a failed execution is what alerts a person. The production deploy updates the job before it changes the service, from three new production environment variables.
