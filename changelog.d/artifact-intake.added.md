Accept artifact submissions, switched off unless `COLLECTOR_INTAKE_ENABLED` is `1`: `POST /v1/submissions` returns signed upload URLs for a private bucket, `POST /v1/submissions/{id}/complete` checks the stored objects and enqueues a worker job through Cloud Tasks, and status and receipt endpoints report the result. The token exchange issues `artifacts:submit` credentials on request. A worker framework, run as a Cloud Run Job, re-hashes each file and calls the handler registered for its kind. Alembic revision `0002_artifact_intake` adds the submission and job tables.
